# راهنمای راه‌اندازی سایت پرینتوپیا روی GitHub و Cloudflare Pages

این راهنما برای افراد مبتدی نوشته شده و همهٔ مراحل را در محیط گرافیکی سایت‌های **GitHub** و **Cloudflare** توضیح می‌دهد.

هدف این است که سایت را بدون کار فنی پیچیده، روی اینترنت بالا بیاورید.

---

## چیزهایی که قبل از شروع لازم دارید

۱. یک حساب GitHub  
۲. یک حساب Cloudflare  
۳. فایل‌های پروژهٔ سایت پرینتوپیا  
۴. یک دامنه، اگر می‌خواهید سایت روی آدرس اختصاصی شما باز شود

اگر دامنه ندارید، Cloudflare خودش یک آدرس رایگان شبیه این می‌دهد:

`your-project.pages.dev`

---

## مرحله ۱: وارد GitHub شوید

۱. مرورگر را باز کنید.
۲. وارد سایت GitHub شوید:

`github.com`

۳. وارد حساب کاربری خود شوید.

---

## مرحله ۲: یک مخزن جدید بسازید

۱. در GitHub، بالای صفحه روی دکمهٔ **+** بزنید.
۲. گزینهٔ **New repository** را انتخاب کنید.
۳. در قسمت **Repository name** یک نام برای پروژه بنویسید، مثلاً:

`printopia`

۴. گزینهٔ **Private** را انتخاب کنید تا مخزن خصوصی باشد.
۵. روی دکمهٔ **Create repository** بزنید.

حالا یک مخزن خالی ساخته شده است.

---

## مرحله ۳: فایل‌های پروژه را داخل GitHub بگذارید

۱. وارد صفحهٔ مخزنی شوید که ساختید.
۲. اگر صفحه خالی است، روی گزینهٔ **uploading an existing file** بزنید.
۳. همهٔ فایل‌ها و پوشه‌های پروژه را انتخاب کنید و داخل صفحه بکشید.
۴. صبر کنید تا فایل‌ها کامل بارگذاری شوند.
۵. پایین صفحه، روی دکمهٔ **Commit changes** بزنید.

بعد از این مرحله، فایل‌های سایت داخل GitHub قرار گرفته‌اند.

---

## مرحله ۴: وارد Cloudflare شوید

۱. مرورگر را باز کنید.
۲. وارد سایت Cloudflare شوید:

`cloudflare.com`

۳. وارد حساب کاربری خود شوید.

---

## مرحله ۵: وارد بخش Pages شوید

۱. در پنل Cloudflare، از منوی سمت چپ گزینهٔ **Workers & Pages** را باز کنید.
۲. وارد تب **Pages** شوید.
۳. روی دکمهٔ **Create application** یا **Create a project** بزنید.
۴. گزینهٔ **Connect to Git** را انتخاب کنید.

---

## مرحله ۶: Cloudflare را به GitHub وصل کنید

۱. Cloudflare از شما می‌خواهد به GitHub وصل شود.
۲. روی دکمهٔ اتصال به GitHub بزنید.
۳. اگر GitHub اجازه خواست، گزینهٔ اجازه دادن را تأیید کنید.
۴. بهتر است فقط همان مخزن پروژهٔ پرینتوپیا را انتخاب کنید.
۵. مخزنی را که ساختید انتخاب کنید.

مثلاً:

`printopia`

---

## مرحله ۷: تنظیمات ساخت سایت در Cloudflare

در صفحهٔ تنظیمات پروژه، Cloudflare چند گزینه نشان می‌دهد.

این موارد را به همین شکل وارد کنید:

### Project name

نام دلخواه پروژه را وارد کنید، مثلاً:

`printopia`

### Production branch

همان شاخه‌ای را انتخاب کنید که GitHub نشان می‌دهد. معمولاً یکی از این دو است:

`main`

یا

`master`

### Framework preset

اگر گزینهٔ **Vite** وجود داشت، آن را انتخاب کنید.

اگر نبود، گزینهٔ **None** یا **React** هم مشکلی ندارد.

### Build command

در این کادر این مقدار را بنویسید:

`npm run build`

### Build output directory

در این کادر این مقدار را بنویسید:

`dist`

نکته: این‌ها را فقط داخل کادرهای Cloudflare می‌نویسید؛ لازم نیست خودتان چیزی را در کامپیوتر اجرا کنید.

---

## مرحله ۸: سایت را منتشر کنید

۱. بعد از وارد کردن تنظیمات، روی دکمهٔ **Save and Deploy** بزنید.
۲. Cloudflare شروع می‌کند به ساخت سایت.
۳. چند دقیقه صبر کنید.
۴. اگر همه‌چیز درست باشد، وضعیت پروژه **Success** یا **Deployed** می‌شود.

بعد از پایان کار، Cloudflare یک آدرس به شما می‌دهد، شبیه این:

`printopia.pages.dev`

روی آن بزنید تا سایت باز شود.

---

## مرحله ۹: اگر سایت باز نشد چه کنم؟

اگر صفحه خطا داد، این موارد را بررسی کنید:

۱. در تنظیمات Cloudflare، مقدار **Build command** دقیقاً این باشد:

`npm run build`

۲. مقدار **Build output directory** دقیقاً این باشد:

`dist`

۳. مطمئن شوید همهٔ فایل‌های پروژه در GitHub آپلود شده‌اند.
۴. اگر Cloudflare خطا نشان داد، وارد بخش **Deployments** شوید و روی آخرین deploy بزنید تا پیام خطا را ببینید.

---

## مرحله ۱۰: اتصال دامنه شخصی به سایت

اگر دامنه دارید، می‌توانید آن را به سایت وصل کنید.

۱. در Cloudflare وارد پروژهٔ Pages شوید.
۲. وارد بخش **Custom domains** شوید.
۳. روی **Set up a custom domain** بزنید.
۴. دامنهٔ خود را وارد کنید، مثلاً:

`example.com`

یا

`www.example.com`

۵. مراحل پیشنهادی Cloudflare را ادامه دهید.
۶. اگر دامنه داخل Cloudflare باشد، معمولاً خودش تنظیمات لازم را انجام می‌دهد.

بعد از چند دقیقه تا چند ساعت، سایت با دامنهٔ شما باز می‌شود.

---

## مرحله ۱۱: بعداً اگر سایت را تغییر دادم چه کنم؟

هر وقت فایل‌های سایت را در GitHub تغییر دهید و تغییرات را ذخیره کنید، Cloudflare به‌صورت خودکار سایت را دوباره می‌سازد و منتشر می‌کند.

یعنی بعد از اتصال اولیه:

۱. فایل‌ها در GitHub تغییر می‌کنند.
۲. Cloudflare خودش متوجه می‌شود.
۳. سایت دوباره ساخته می‌شود.
۴. نسخهٔ جدید آنلاین می‌شود.

---

## مرحله ۱۲: ورود به پنل مدیریت سایت

بعد از اینکه سایت بالا آمد، برای ورود به پنل مدیریت این آدرس را باز کنید:

`آدرس-سایت-شما/admin`

مثلاً:

`printopia.pages.dev/admin`

در حالت ساده و آزمایشی، پنل داخل مرورگر شما کار می‌کند.

---

## نکته مهم درباره پنل مدیریت

در نسخهٔ ساده، اطلاعاتی که در پنل مدیریت وارد می‌کنید، داخل مرورگر همان دستگاه ذخیره می‌شود.

یعنی برای تست، ساخت مقاله، دیدن ظاهر پنل و بررسی سایت کاملاً مناسب است.

اگر بعداً خواستید پنل مدیریت به‌صورت واقعی به GitHub وصل شود و مقاله‌ها را داخل مخزن ذخیره کند، باید تنظیمات پیشرفتهٔ سمت سرور و GitHub App انجام شود.

برای بالا آوردن خود سایت روی Cloudflare Pages، نیازی به انجام تنظیمات پیشرفته ندارید.

---

## خلاصه خیلی کوتاه

۱. در GitHub یک مخزن خصوصی بسازید.  
۲. فایل‌های پروژه را داخل آن آپلود کنید.  
۳. در Cloudflare وارد Workers & Pages شوید.  
۴. گزینهٔ Connect to Git را بزنید.  
۵. مخزن GitHub را انتخاب کنید.  
۶. Build command را روی `npm run build` بگذارید.  
۷. Output directory را روی `dist` بگذارید.  
۸. Save and Deploy را بزنید.  
۹. لینک سایت را از Cloudflare باز کنید.
