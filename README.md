# راهنمای سادهٔ پرینتوپیا 🖨️

این راهنما برای کسی است که **تا حالا سایت راه‌اندازی نکرده**. همه‌چیز به زبان ساده فارسی توضیح داده شده.

---

## ۱) این سایت چگونه کار می‌کند؟

مدیریت سایت از یک پنل مخفی به‌نام `/admin` انجام می‌شود:

```
ورود به پنل مدیریت   (/admin)
        ↓
ساخت یا ویرایش محتوا
        ↓
ذخیره و نمایش در سایت
```

- شما در پنل می‌نویسید؛ سایت تغییر می‌کند.
- «پنل مدیریت» همان صفحه‌ای است که فقط شما می‌بینید و از آن سایت را اداره می‌کنید.

> دربارهٔ وضعیت واقعی پروژه یک نکتهٔ مهم در بخش «نکات صادقانه» در انتها آمده؛ حتماً بخوانید.

---

## ۲) شروع سریع در چند دقیقه

کوتاه‌ترین مسیر:

1. آدرس زیر را در مرورگر باز کن: `https://YOUR-DOMAIN/admin/setup`
2. دکمهٔ **«شروع راه‌اندازی»** را بزن.
3. در مرحلهٔ **«ساخت حساب مدیر»** یک رمز عبور انتخاب کن و **«تولید کلیدهای امن»** را بزن.
4. دو کلید ساخته می‌شود؛ هرکدام را با دکمهٔ **«کپی کردن»** بردار.
5. در Cloudflare این دو کلید را اضافه کن (راهنما در همان صفحه آمده).
6. مراحل را تا **«راه‌اندازی کامل شد»** ادامه بده و وارد پنل شو.

⚠️ یک کار هست که **نمی‌شود دور زد**: خودِ صاحبِ حسابِ Cloudflare باید یک‌بار این دو کلید را در داشبورد اضافه کند. این تأیید فقط یک‌بار است و برای امنیت لازم است.

---

## ۳) قبل از شروع

- [ ] یک حساب **Cloudflare** (dash.cloudflare.com).
- [ ] سایت روی Cloudflare منتشر (deploy) شده باشد.
- [ ] (اختیاری) یک حساب **GitHub** اگر کد سایت از آنجا به‌روز می‌شود.
- [ ] دامنهٔ شخصی (اختیاری).

🚨 این‌ها را **هرگز** با کسی به اشتراک نگذار:
- رمزِ مدیر، `ADMIN_PASSWORD_HASH`، `SESSION_SECRET`
- کلید خصوصی، توکن، فایل `.env`

---

## ۴) راه‌اندازی خودکار با Setup Wizard

آدرس جادویی:
```
https://YOUR-DOMAIN/admin/setup
```

این «ویزارد» (راهنمای گام‌به‌گام) مراحل را یکی‌یکی نشان می‌دهد.

### مراحل ویزارد

**گام ۱ — خوش آمدید**
توضیح سادهٔ مسیر. دکمهٔ «شروع راه‌اندازی» را بزن.

**گام ۲ — بررسی وضعیت پروژه**
چند بررسی ساده انجام می‌شود. «ادامه» را بزن.

**گام ۳ — ساخت حساب مدیر**
- رمز عبور و تکرار آن را بنویس.
- یک نوار سبز/قرمزِ «قدرت رمز» می‌بینی (رمز را نشان نمی‌دهد).
- «تولید کلیدهای امن» را بزن. **تو هیچ چیزی را محاسبه نمی‌کنی**؛ کلیدها خودکار ساخته می‌شوند.

**گام ۴ — افزودن کلیدها به Cloudflare**
- دو جعبه می‌بینی: `ADMIN_PASSWORD_HASH` و `SESSION_SECRET`.
- هرکدام را «کپی کردن» بزن.
- طبق راهنما در Cloudflare اضافه کن (در ادامه توضیح داده‌ام).
- وقتی اطمینان داری اضافه‌کردی، «ادامه» را بزن.
- دکمهٔ «پاک‌کردن از حافظه» کلیدها را از مرورگر پاک می‌کند (امن).

**گام ۵ — اتصال اختیاری GitHub**
- GitHub فقط برای به‌روزرسانی **کد** است؛ برای محتوا لازم نیست. «ادامه» را بزن.

**گام ۶ — بررسی نهایی**
- سه مورد را تیک بزن (کلیدها اضافه شد، رمز را یادداشت کردی، سایت باز می‌شود).
- «تکمیل راه‌اندازی» را بزن.

**گام ۷ — راه‌اندازی کامل شد**
- «ورود به پنل مدیریت» را بزن.

### اگر وسط کار قطع شد
- نگران نباش. دوباره `/admin/setup` را باز کن و از همان مرحله ادامه بده.
- اگر کلیدها را پاک کرده‌ای، یک رمز جدید بده و کلیدهای تازه بساز.
- هیچ منبعی به‌صورت خودکار خراب نمی‌شود.

### توقف امن
- دکمهٔ «لغو و پاک‌کردن» اطلاعات واردشده را از حافظه پاک می‌کند.

> اگر ویزارد قبلاً کامل شده باشد، دوباره باز کردنش صفحهٔ قفل‌شده نشان می‌دهد و فقط «رفتن به پنل مدیریت» می‌دهد.

---

## ۵) ساخت کلید محدود Cloudflare (آیا لازم است؟)

❌ **برای راه‌اندازی این پروژه، هیچ کلیدِ API یا Global API Key لازم نیست.**
ویزارد خودش کلیدهای لازم (`ADMIN_PASSWORD_HASH` و `SESSION_SECRET`) را می‌سازد.

🚨 **هرگز** از «Global API Key» استفاده نکن؛ دسترسی کامل و خطرناک به کل حساب می‌دهد.

> اگر روزی در نسخهٔ آینده‌تر، ساخت خودکار منابع (مثل پایگاه‌داده) خواستی، فقط از یک **توکنِ محدود و دارای اعتبار زمانی** در مسیر `My Profile → API Tokens` استفاده کن، با کمترین دسترسی (مثلاً فقط `Workers Scripts` یا `D1`)، و فقط برای همان یک حساب. پس از کار، آن را باطل کن.

---

## ۶) ورود به پنل مدیریت

- آدرس: `https://YOUR-DOMAIN/admin`
- رمز عبور را وارد کن و «ورود» را بزن.
- خروج: از منو، «خروج از حساب».

اگر ورود شکست خورد:
- مطمئن شو کلیدها را درست در Cloudflare اضافه کرده‌ای.
- اگر «تلاش‌های زیادی» دیدی، چند دقیقه صبر کن.

> در نسخهٔ فعلی، پنل در «حالت پیش‌نمایش» کار می‌کند (هر رمزی باز می‌کند). ورودِ امنِ واقعی پس از فعال‌شدن بخش سرور روشن می‌شود. کلیدها را اکنون برای آن زمان آماده می‌کنیم.

---

## ۷) کار با پنل مدیریت

از منوی کناری:

| بخش | کار |
|---|---|
| پیشخوان | نمای کلی و دکمه‌های سریع |
| پست‌ها و مقالات | ساخت/ویرایش/انتشار مقاله‌ها |
| محصولات / دسته‌بندی محصولات | مدیریت محصولات |
| دسته‌بندی‌ها | دسته‌بندی مقاله‌ها |
| صفحات سایت | صفحات ثابت (درباره، تماس و ...) |
| رسانه‌ها | آپلود عکس (با Alt فارسی) |
| منوها و ناوبری | منو و فوتر |
| ظاهر سایت | رنگ‌ها، تم، شبکه‌های اجتماعی |
| سئو / ریدایرکت‌ها | تنظیمات جستجو و مسیرها |
| تنظیمات سایت | نام، تماس، ارسال رایگان |

### مقاله‌ها
- **ذخیره پیش‌نویس**: بدون نمایش در سایت.
- **پیش‌نمایش**: دیدن قبل از انتشار.
- **انتشار**: نمایش در سایت.
- **لغو انتشار / بایگانی**: مخفی بدون حذف.
- **حذف**: فقط با تأیید؛ قابل بازگشت نیست (اول بایگانی کن اگر شک داری).

### عکس‌ها
- اول **متن جایگزین فارسی (Alt)** را بنویس (الزامی).
- فرمت: WebP، AVIF، JPG، PNG — حداکثر ۳ مگابایت.

---

## ۸) GitHub و Cloudflare چه زمانی لازم‌اند؟

- **محتوا** (مقاله، محصول، متن، عکس): فقط از پنل مدیریت انجام می‌شود؛ به GitHub نیاز ندارد.
- **کدِ سایت**: اگر از GitHub منتشر می‌شود، هر تغییرِ کد، یک انتشار (deploy) جدید در Cloudflare می‌سازد.
- بررسی وضعیت انتشار: داشبورد Cloudflare → پروژه → **Deployments** (🟢 موفق / 🟡 در حال ساخت / 🔴 ناموفق).

---

## ۹) رفع خطاهای رایج

| مشکل | راه‌حل ساده |
|---|---|
| `/admin` صفحهٔ اصلی را باز کرد | بررسی کن deploy موفق بوده؛ صفحه را سخت بازخوانی کن |
| `/admin/setup` باز نمی‌شود | deploy را چک کن؛ اگر خطاست، گزارش (Log) را ببین |
| ورود کار نکرد | کلیدها درست در Cloudflare اضافه شده؟ |
| ویزارد وسط کار قطع شد | دوباره باز کن و ادامه بده؛ چیزی خراب نمی‌شود |
| محتوا در سایت نمایش داده نشد | در حالت پیش‌نمایش، تغییرات در همان مرورگر ذخیره می‌شوند (بخش نکات صادقانه) |
| آپلود عکس ناموفق | حجم/فرمت را چک کن و Alt را بنویس |
| منوی موبایل کار نکرد | deploy تازه را بازخوانی کن |
| کلید اشتباه افشا شد | فوراً در Cloudflare مقدار تازه بساز (همان نام) |

---

## ۱۰) نکات امنیتی بسیار مهم

- 🚨 هرگز: رمز مدیر، `ADMIN_PASSWORD_HASH`، `SESSION_SECRET`، کلید خصوصی، توکن، یا فایل `.env` را به اشتراک نگذار یا در GitHub نگذار.
- اگر رازی افشا شد، **فوراً** در Cloudflare یک مقدار تازه بساز (همان نام).
- کلیدها فقط در فیلدهای **Secret** در داشبورد Cloudflare قرار بگیرند.
- مخزن GitHub را خصوصی نگه دار.

---

## ۱۱) واژه‌نامه ساده

- **Worker**: نوع استقرارِ سایت در Cloudflare (همین پروژه از این نوع است).
- **Deploy / انتشار**: قابل‌دیدن‌کردن سایت روی اینترنت.
- **پنل مدیریت (/admin)**: صفحه‌ای که فقط شما سایت را از آن اداره می‌کنید.
- **Secret (کلید مخفی)**: مقداری که پنهان نگه‌داری می‌شود و سایت از آن استفاده می‌کند.
- **هاش (Hash)**: نسخهٔ رمزشدهٔ رمز که ویزارد خودش می‌سازد؛ نیازی به فهمیدنش نداری.
- **GitHub repository (مخزن)**: پوشهٔ آنلاینِ کد سایت.
- **D1 / R2**: پایگاه‌داده و فضای تصویرِ Cloudflare (در این نسخه استفاده **نمی‌شوند**).

---

## ⚠️ نکات صادقانه (مهم)

برای اینکه دروغی در کار نباشد:

1. این پروژه به‌صورت یک **سایت ایستا روی Cloudflare Worker** منتشر می‌شود و بخش سرور (توابع `/api/admin/*`) در این نسخه **فعال نیست**. به همین دلیل:
   - پنل مدیریت در «حالت پیش‌نمایش» کار می‌کند: ورود با هر رمزی باز می‌شود و محتوا فقط در **همان مرورگرِ شما** ذخیره می‌شود.
2. ویزارد، `ADMIN_PASSWORD_HASH` و `SESSION_SECRET` را **خودکار و درست** می‌سازد تا با فهمیدن هش درگیر نشوید. این کلیدها برای زمانی است که بخش سرور فعال شود.
3. **D1 و R2 ساخته نمی‌شوند**، چون این پروژه از آن‌ها استفاده نمی‌کند و افزودنشان نیازمند بازنویسیِ بخش سرور است.
4. هیچ‌گونه «Global API Key» یا توکنِ Cloudflare یا توکنِ GitHub درخواست نمی‌شود.

---

## خلاصهٔ نهایی

- **مسیر شروع:** `https://YOUR-DOMAIN/admin/setup`
- **یک کارِ اجتناب‌ناپذیر:** اضافه‌کردنِ دو کلید در Cloudflare (توسط خود صاحب حساب).
- **نتیجه:** پنل مدیریت آماده است و محتوا قابل ویرایش.
- **محدودیت صادقانه:** ورودِ امنِ واقعی و اشتراک محتوا میان دستگاه‌ها، نیازمند فعال‌کردن بخش سرور در آینده است.
