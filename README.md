# راهنمای راه‌اندازی سایت در GitHub و Cloudflare ☁️

این راهنما مخصوص مبتدی‌هاست. هیچ دستور فنی لازم نیست؛ همه‌چیز با کلیک در سایت‌های GitHub و Cloudflare انجام می‌شود.

با این کار، سایت شما یک آدرس اینترنتی می‌گیرد و آنلاین می‌شود. 🎉

---

## مرحلهٔ ۱) در GitHub وارد شوید

1. به سایت **github.com** بروید.
2. اگر حساب ندارید، یک حساب رایگان بسازید و وارد شوید.

---

## مرحلهٔ ۲) یک مخزن (Repository) جدید بسازید

1. در GitHub، دکمهٔ **«+»** بالا-راست را بزنید و **New repository** را انتخاب کنید.
2. یک اسم دلخواه بنویسید (مثلاً `printopia`).
3. گزینهٔ **Private** (خصوصی) را انتخاب کنید تا سایتتان عمومی نباشد.
4. دکمهٔ **Create repository** را بزنید.

---

## مرحلهٔ ۳) فایل‌های پروژه را در GitHub آپلود کنید

1. در صفحهٔ مخزن تازه‌ساخته‌شده، روی **uploading an existing file** (یا دکمهٔ **Add file → Upload files**) بزنید.
2. همهٔ فایل‌ها و پوشه‌های پروژه را بکشید و اینجا رها کنید (Drag & Drop).
3. ⚠️ **مهم:** پوشهٔ `node_modules` را آپلود **نکنید** (بسیار سنگین است و نیازی نیست).
4. پایین صفحه، دکمهٔ **Commit changes** را بزنید و صبر کنید تا فایل‌ها بالاگذار شوند.

> فایل‌های اصلی که باید آپلود کنید: پوشه‌های `src`، `functions`، `public` (اگر هست)، و فایل‌های `package.json`، `vite.config.ts`، `tsconfig.json`، `index.html`.

---

## مرحلهٔ ۴) در Cloudflare وارد شوید

1. به سایت **dash.cloudflare.com** بروید.
2. یک حساب رایگان بسازید (یا وارد شوید).

---

## مرحلهٔ ۵) یک پروژهٔ Pages بسازید و به GitHub وصل کنید

1. در منوی سمت چپ Cloudflare، بخش **Workers & Pages** را باز کنید.
2. دکمهٔ **Create** را بزنید.
3. تب **Pages** را انتخاب کنید.
4. دکمهٔ **Connect to Git** را بزنید.
5. به GitHub متصل شوید و اجازه دهید Cloudflare به مخزن شما دسترسی داشته باشد.
6. مخزنی که در مرحلهٔ ۲ ساختید (مثلاً `printopia`) را انتخاب کنید و **Begin setup** را بزنید.

---

## مرحلهٔ ۶) تنظیمات ساخت (Build) را وارد کنید

در صفحهٔ تنظیمات، این موارد را دقیقاً همین‌طور بنویسید:

| فیلد | مقدار |
| --- | --- |
| Project name | هر اسمی (مثلاً `printopia`) |
| Production branch | `main` |
| Framework preset | **None** |
| Build command | `npm run build` |
| Build output directory | `dist` |

سپس بخش **Environment variables** را باز کنید و این مورد را اضافه کنید (برای اینکه ساخت بدون خطا انجام شود):

- متغیر: `NODE_VERSION`
- مقدار: `20`

در نهایت دکمهٔ **Save and Deploy** را بزنید.

---

## مرحلهٔ ۷) منتظر بمانید تا سایت ساخته شود ⏳

1. Cloudflare شروع به ساخت سایت می‌کند (چند دقیقه طول می‌کشد).
2. وقتی وضعیت **Success** 🟢 شد، یعنی سایت آماده است.
3. بالای صفحه یک آدرس اینترنتی می‌بینید (مشابه `printopia.pages.dev`). روی آن بزنید.

✅ سایت شما حالا آنلاین است!

---

## مرحلهٔ ۸) وارد پنل مدیریت شوید 🔐

1. آدرس سایتتان را باز کنید.
2. به انتهای آدرس `/admin` را اضافه کنید و Enter بزنید.
   - مثال: `printopia.pages.dev/admin`
3. یک رمز تایپ کنید و **«ورود»** را بزنید.
   - در حالت آزمایشی، هر رمزی قبول می‌شود.

---

## مرحلهٔ ۹) از این به بعد، آپدیت سایت خودکار است 🔁

هر بار که در GitHub فایلی را تغییر دهید (مثلاً یک فایل را ویرایش یا اضافه کنید و **Commit** بزنید)، Cloudflare خودش متوجه می‌شود و سایت را دوباره می‌سازد و به‌روز می‌کند. شما کاری ندارید.

---

## یک نکتهٔ ساده 📌

- اگر فقط می‌خواهید سایت و پنل مدیریت را ببینید و تست کنید، همین مراحل کافی است.
- بخش «انتشار خودکار مقاله از پنل به GitHub» یک قابلیت پیشرفته‌تر است که بعداً و در صورت نیاز فعال می‌شود. برای شروع، نیازی به آن ندارید.
