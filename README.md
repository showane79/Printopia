# پرینتوپیا — فروشگاه چاپ سه‌بعدی با پنل مدیریت

یک فروشگاه آنلاین کامل برای محصولات چاپ سه‌بعدی، با پنل مدیریت فارسی و راه‌اندازی خودکار.

## ویژگی‌ها

- **پنل مدیریت فارسی** — ویرایش محصولات، مقالات و تنظیمات سایت
- **راه‌اندازی یک‌کلیکی** — اتصال خودکار به Cloudflare و ساخت پایگاه‌داده
- **ورود امن** — احراز هویت با رمز عبور و نشست HttpOnly
- **مدیریت محصولات** — افزودن، ویرایش و انتشار محصولات با عکس و جزئیات کامل
- **سیستم وبلاگ** — نوشتن و انتشار مقالات با ویرایشگر بلوکی
- **طراحی ریسپانسیو** — کاملاً بهینه برای موبایل، تبلت و دسکتاپ
- **تم تاریک/روشن** — تغییر خودکار یا دستی پوسته
- **بهینه‌سازی سئو** — متاتگ‌ها، نقشه سایت و Open Graph

## راه‌اندازی

### ۱. پیش‌نیازها

- حساب Cloudflare (رایگان)
- مخزن GitHub متصل به Cloudflare Pages

### ۲. نصب

این پروژه به‌صورت خودکار روی Cloudflare Pages ساخته می‌شود:

```bash
npm install
npm run build
```

### ۳. اولین راه‌اندازی

پس از انتشار سایت روی Cloudflare Pages:

1. به آدرس `/admin/setup` بروید
2. یک توکن API از Cloudflare بسازید با سه دسترسی زیر:
   - **Account Settings: Read**
   - **D1: Edit**
   - **Workers Scripts: Edit**
3. توکن را در کادر وارد کنید — سیستم به‌صورت خودکار:
   - پایگاه‌داده D1 می‌سازد
   - جدول‌ها را ایجاد می‌کند
   - اتصال امن برقرار می‌کند
4. یک رمز عبور برای حساب مدیر تعریف کنید
5. وارد پنل مدیریت شوید از `/admin`

### ۴. بهینه‌سازی سرعت (اختیاری)

برای سریع‌ترین دسترسی، شناسه پایگاه‌داده را در `wrangler.jsonc` ثبت کنید:

```jsonc
{
  "name": "printopia",
  "compatibility_date": "2024-01-01",
  "d1_databases": [
    {
      "binding": "DB",
      "database_name": "printopia-cms",
      "database_id": "شناسه‌ای که در مرحله راه‌اندازی دریافت کردید"
    }
  ]
}
```

این کار اتصال REST را به اتصال مستقیم (سریع‌تر و رایگان) تبدیل می‌کند.

## نحوه استفاده

### مدیریت محصولات

1. وارد پنل شوید از `/admin`
2. روی **محصولات** کلیک کنید
3. **افزودن محصول** را بزنید
4. عنوان، قیمت، تصویر و توضیحات را وارد کنید
5. وضعیت را روی **منتشر شده** بگذارید و ذخیره کنید
6. محصول در صفحه فروشگاه نمایش داده می‌شود

### نوشتن مقاله

1. وارد **پست‌ها و مقالات** شوید
2. **افزودن پست** را بزنید
3. محتوا را با ویرایشگر بلوکی بنویسید (سرتیتر، پاراگراف، لیست، تصویر)
4. دسته‌بندی و تصویر شاخص را اضافه کنید
5. وضعیت را روی **منتشر شده** بگذارید
6. مقاله در بلاگ نمایش داده می‌شود

### تنظیمات سایت

در بخش **تنظیمات سایت** می‌توانید:
- نام فروشگاه را تغییر دهید
- شماره تماس و ایمیل را ویرایش کنید
- آستانه ارسال رایگان را تعیین کنید

## معماری

### فرانت‌اند
- **React 19** + **TypeScript**
- **React Router** برای مسیریابی
- **Tailwind CSS** برای استایل
- **Vite** برای بیلد

### بک‌اند
- **Cloudflare Pages** — میزبانی استاتیک
- **Cloudflare Workers** — API بدون سرور
- **Cloudflare D1** — پایگاه‌داده SQLite

### دسترسی به داده

Worker از دو روش به D1 دسترسی دارد:
1. **Binding مستقیم** — سریع و رایگان (نیاز به تنظیم `wrangler.jsonc`)
2. **REST API** — فعال پس از راه‌اندازی، بدون نیاز به ویرایش مخزن

هر دو روش یکسان کار می‌کنند — REST برای شروع سریع، binding برای بهترین سرعت.

## امنیت

- **احراز هویت امن** — رمز با PBKDF2 هش می‌شود (۱۰۰٬۰۰۰ تکرار)
- **نشست HttpOnly** — کوکی در جاوااسکریپت قابل دسترسی نیست
- **Rate limiting** — محدودیت تعداد تلاش برای ورود و راه‌اندازی
- **توکن یک‌بار مصرف** — توکن Cloudflare فقط در هنگام راه‌اندازی استفاده می‌شود

## توسعه محلی

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# بیلد برای تولید
npm run build

# پیش‌نمایش بیلد
npm run preview
```

**نکته مهم:** Worker و D1 فقط در محیط Cloudflare کار می‌کنند. برای توسعه محلی، پنل مدیریت از localStorage استفاده می‌کند.

## عیب‌یابی

### پنل مدیریت باز نمی‌شود

- مطمئن شوید سایت روی Cloudflare Pages منتشر شده
- آدرس `/admin/setup` را امتحان کنید
- کنسول مرورگر را برای خطاها بررسی کنید

### محصولات در سایت نمایش داده نمی‌شوند

- مطمئن شوید وضعیت محصول **منتشر شده** است
- کش مرورگر را پاک کنید
- Worker logs را در داشبورد Cloudflare بررسی کنید

### خطای "پایگاه‌داده در دسترس نیست"

- راه‌اندازی را کامل کنید از `/admin/setup`
- توکن API را دوباره بسازید با دسترسی‌های لازم
- مطمئن شوید D1 در داشبورد Cloudflare ایجاد شده

## محدودیت‌ها

- **یک مدیر** — فقط یک حساب مدیر پشتیبانی می‌شود
- **بدون رسانه‌های پیشرفته** — آپلود تصویر نیاز به تنظیم اضافی دارد
- **محیط محلی محدود** — Worker و D1 فقط در Cloudflare کار می‌کنند
